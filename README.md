# Markdown 富文本复制工具

一个无需安装、无需构建、可离线运行的 Markdown 排版工具。

将 Markdown 文本粘贴或读取到浏览器中，实时查看排版效果，再通过“复制富文本”粘贴到 Microsoft Word、WPS 等文档编辑器，并尽量保持网页中的标题、表格、代码块、引用、图片和 Mermaid 图表样式。

> 本工具用于复制可粘贴到文档编辑器的富文本，不会直接生成 `.docx` 文件。

## 功能特性

- **Markdown 输入**：支持粘贴、编辑 Markdown 文本。
- **打开本地文件**：支持读取 `.md`、`.markdown` 和普通文本文件。
- **实时预览**：输入内容变化后立即更新排版结果。
- **富文本复制**：复制后可直接粘贴到 Word 或 WPS。
- **Word 排版优化**：处理表格宽度、长字段换行、段落间距和分隔线。
- **代码块样式**：保留浅灰色背景、等宽字体和代码结构。
- **区块引用样式**：保留引用底色和左侧边框。
- **图片支持**：显示 Markdown 图片，并限制图片宽度以适配文档页面。
- **Mermaid 支持**：离线渲染 Mermaid 图表，复制时转换为可粘贴到 Word 的图片。
- **Mermaid 大图查看**：点击图表后以模态窗口打开，支持缩放、拖动和原始尺寸恢复。
- **浮动目录**：自动提取一级、二级标题，支持章节跳转和当前位置高亮。
- **可收起输入区**：以抽屉方式收起左侧 Markdown 输入区域，扩大预览空间。
- **快速返回顶部**：页面向下滚动后显示固定的“跳到顶部”按钮。
- **完全离线**：Mermaid 运行代码已经内嵌到 `index.html`，页面不会加载外部脚本或样式。

## 支持的 Markdown 内容

| 类型 | 支持情况 |

| 一级至六级标题 | 支持 |
| 普通段落 | 支持 |
| 粗体、斜体 | 支持 |
| 行内代码、代码块 | 支持 |
| 有序列表、无序列表 | 支持 |
| 链接、图片 | 支持 |
| 表格 | 支持 |
| 区块引用 | 支持 |

| Mermaid 代码块 | 支持 |

## 快速开始

1. 下载或克隆本项目。
2. 使用现代浏览器直接打开 `index.html`。
3. 在左侧粘贴 Markdown，或点击“打开文件”选择本地 Markdown 文件。
4. 在右侧检查实时排版结果。
5. 点击页面上方的“复制富文本”。
6. 在 Word 或 WPS 中直接粘贴。

无需启动 Web 服务器，也不需要安装 npm 依赖。

## Mermaid 使用示例

````markdown
```mermaid
flowchart LR
  A[输入 Markdown] --> B[实时预览]
  B --> C[复制富文本]
```
````

渲染完成后可以点击图表打开大图。大图窗口支持：

- 鼠标滚轮或 `+`、`-` 按钮缩放。
- 按住图表区域拖动查看。
- 点击 `1:1` 恢复 SVG 原始尺寸。
- 点击右上角关闭按钮、遮罩区域或按 `Esc` 关闭。

## 离线使用

Mermaid 运行代码已经直接内嵌到 `index.html`。断开互联网后，Markdown 预览、Mermaid 渲染、目录跳转和富文本复制功能仍可正常使用。

默认示例引用了同目录中的 `images.png`。该图片只用于测试本地图片显示和复制；如果移动 `index.html`，请同时保留此图片，或在 Markdown 中替换为自己的图片路径。

安装 Node.js 后，在本目录运行：

```shell
node --test md2doc.test.mjs
```

## 浏览器兼容性

推荐使用较新版本的 Microsoft Edge、Google Chrome 或其他 Chromium 浏览器。不同版本的 Word、WPS 和浏览器对剪贴板富文本的解析可能略有差异。

## 隐私说明

Markdown 文本和本地文件均在浏览器中处理，不会上传到服务器。本工具打开时也不会自动请求外部代码或样式资源。
